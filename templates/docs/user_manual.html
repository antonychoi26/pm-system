1. 系統概覽

本系統是為物業管理團隊度身設計的工作追蹤平台，協助各員工及主管有效管理旗下多個屋苑的日常工作事項。

  • 集中管理多個屋苑的工作事項，一目了然
  • 每日工作清單讓員工清楚知道今天需要跟進哪些事項
  • 完整的跟進記錄（Activity Log），記錄每一個處理步驟
  • 支援附件上傳（圖片、文件、PDF、Outlook 郵件等）
  • 主管可透過儀表板掌握整體狀況及逾期事項
  • 工作日曆提供視覺化時間軸，方便排期規劃
系統網址： antonychoi.pythonanywhere.com  （建議使用 Chrome 或 Edge 瀏覽器）

2. 用戶角色與權限

系統設有三個角色層級，權限由高至低：

角色 可執行操作
管理員 全部功能，包括：新增 / 刪除用戶、管理屋苑、設定事項種類及狀況、查看所有人記錄、匯入數據
主管 新增及編輯事項、指派員工、查看所有屋苑報告、管理用戶（限本屋苑）、查看儀表板統計
員工 查看及更新自己負責的事項、新增跟進記錄、管理個人每日工作清單、上傳附件
員工只能看到自己被指派的事項；主管及管理員可查看所有事項。

3. 登入系統

登入步驟

1開啟瀏覽器，前往系統網址
2輸入你的用戶名稱及密碼（由管理員提供）
3按「登入」按鈕
4成功後自動跳轉至儀表板
共用電腦提示：每個瀏覽器分頁擁有獨立登入狀態，使用完畢請按右下角「登出」，避免下一位同事看到你的資料。

4. 儀表板

登入後的首頁，顯示整體工作狀況摘要。

主要資訊

  • 統計卡片：顯示今日新增、進行中、逾期及本月完成事項數量
  • 逾期警示：列出所有已超過到期日但尚未完成的事項，按屋苑顯示
  • 各屋苑事項分佈：以圖表呈現各屋苑事項比例
  • 員工工作量統計：顯示各員工目前負責的進行中事項數量
  • 最新跟進記錄：顯示最近的 Activity Log 條目
主管及管理員可看到全部屋苑數據；員工只看到自己負責的事項統計。

5. 事項管理

5.1 新增事項

1點選左側「新增事項」
2填寫事項標題（必填）、選擇所屬屋苑、種類、優先級及到期日
3在「指派跟進人員」欄位選擇負責員工（可多選）
4填寫描述（可選），按「儲存」完成新增

系統會自動生成事項編號（如 ALS-2025-001），格式為「屋苑代碼—年份—流水號」。

5.2 事項狀況流程

每個事項依照以下流程推進：

新增 跟進中 完成 已完成
  • 新增：剛建立，尚未開始處理
  • 跟進中：正在處理中
  • 完成：工作完成，等待主管確認
  • 已完成：主管確認完結，事項存檔

5.3 事項詳情頁

點擊任何事項編號或標題即可進入詳情頁，包含：

  • 基本資料：屋苑、種類、優先級、到期日、負責人員
  • 描述：事項的詳細說明
  • 跟進記錄（Activity Log）：所有歷史操作及備註，可新增跟進記錄
  • 附件：上傳相關文件、圖片或郵件（支援 .pdf、.jpg、.png、.docx、.msg、.eml 等格式）

5.4 新增跟進記錄

1進入事項詳情頁
2在「新增跟進記錄」文字框輸入內容（如：「已聯絡承辦商，預計下週到場」）
3如需要，同時更新事項狀況
4按「儲存記錄」完成

5.5 事項清單視圖

左側選單「事項清單」提供兩種視圖：

  • 列表視圖：表格形式，可按屋苑、狀況、優先級篩選
  • 看板視圖：以欄位形式展示各狀況的事項，直觀拖拉管理

6. 每日工作清單

每日工作清單是員工的個人工作管家，幫助你整理今天需要處理的事項。

6.1 加入每日清單

1點選左側「每日工作清單」
2按右上角「＋ 從事項加入」按鈕
3從彈出清單中選擇你負責的事項，按「加入今日清單」

6.2 記錄今日工作

  • 點擊清單中任一事項，彈出編輯視窗
  • 在「今日備註」欄位輸入當天的工作內容或進度
  • 完成後勾選「標記為完成」，該事項會顯示為已完成狀態
  • 按「✏️ 事項編號」按鈕可直接跳轉至事項主頁面，新增正式跟進記錄

6.3 清單分組顯示

每日工作清單會自動按以下方式分組顯示：

  • 待處理：今日未完成的事項
  • 已完成：今日已標記為完成的事項
每日清單每天重置，昨日的記錄不會自動延續至今天。如需繼續跟進，請重新加入清單。

7. 工作日曆

工作日曆以月曆形式顯示所有有到期日的事項，方便規劃及跟進時間表。

  • 每個日期格子內顯示當天到期的事項數量及名稱
  • 可按屋苑篩選，只顯示指定屋苑的事項
  • 點擊事項可直接跳轉至事項詳情頁
  • 逾期未完成的事項會以紅色標示
建議主管定期查看工作日曆，確保所有到期事項均有人跟進。

8. 報告功能

8.1 生成報告

點選左側「生成報告」，可匯出以下報告：

  • 事項報告：按屋苑、日期範圍、狀況篩選，匯出 Excel 格式
  • 報告包含事項編號、標題、屋苑、種類、優先級、負責人、到期日、狀況等資訊

8.2 匯入數據（主管 / 管理員）

支援從 Excel 檔案批量匯入事項，適合系統初始化或大量資料遷移時使用。

匯入前請確保 Excel 格式符合系統要求，如不確定請聯絡管理員。

9. 管理設定（主管 / 管理員）

「管理設定」部分只對主管及管理員顯示，包含以下功能：

9.1 屋苑管理（管理員）

  • 新增、編輯、啟用 / 停用屋苑
  • 每個屋苑有中英文名稱及代碼（用於自動生成事項編號）

9.2 用戶管理

  • 新增用戶：填寫用戶名稱、顯示名稱、角色，系統會自動設定初始密碼
  • 編輯用戶資料及角色
  • 停用用戶（停用後該用戶無法登入）
  • 指派用戶至所屬屋苑

9.3 事項種類

  • 管理事項的分類標籤（如：工程、投訴、財務等）
  • 可新增、編輯或調整排列順序

9.4 事項狀況

  • 管理事項的狀況標籤（如：新增、跟進中、完成、已完成）
  • 可設定哪個狀況為「完結」狀態（Terminal），完結狀態的事項不會在逾期警示中顯示

9.5 工作流程範本

  • 預設常用工作流程的待辦事項清單（例如：新居入伙流程、裝修申請流程）
  • 新增事項時可套用範本，自動生成標準化工作步驟

10. 使用貼士

日常工作建議流程

  1. 每天上班後，先查看儀表板，了解逾期及今日需處理事項
  2. 進入每日工作清單，將今天需跟進的事項加入清單
  3. 逐一跟進事項，在事項詳情頁新增跟進記錄
  4. 完成後在每日清單中標記為完成
  5. 下班前再次檢視儀表板，確認所有緊急事項已妥善處理

常見問題

問題解決方法
登入後看不到某些事項 員工只能看到自己被指派的事項，如需查看請聯絡主管
無法更改事項狀況 確認你已被指派為負責人，或聯絡主管協助
附件上傳失敗 檔案大小上限為 20MB，請確認格式（jpg/png/pdf/docx/msg/eml）
每日清單消失了 每日清單每天重置，昨天的記錄需重新加入
忘記密碼 聯絡管理員重設密碼
技術支援：如遇系統問題，請聯絡系統管理員，並盡量提供截圖及問題說明，以便快速協助。
